# Changelog — 2026-08-23 22:37:12 +0800

会话/任务主题：按 OpenAPI 3 oauth2 client_credentials 重构为 tokenUrl + 通用网关，去掉旧 URL 与兼容层

## 1. 背景与目标

- 原先四条独立 POST：`/auth/token`（用户名密码换 UUID Bearer）、`/api/posts`、`/api/photos`、`/api/imgdef`
- 目标：成熟开放平台形态。换票地址遵循 OpenAPI 3 `oauth2.flows.clientCredentials.tokenUrl`；业务只留一个网关，能力用 `method` 开通，不按业务拆 URL
- 不保留旧路径、旧信封、用户名密码发 Token

## 2. 代码改动

| 路径 | 变更 |
|------|------|
| `config/app.toml` | `[[apps]]`：`client_id` / `client_secret` / 已开通 `methods` |
| `src/service/apps.rs` | 启动加载应用注册表，校验 method 白名单 |
| `src/service/token.rs` | 票绑定 client 与 scope；允许多张未过期票 |
| `src/handler/token.rs` | `POST /v3/oauth/token`，form-urlencoded + HTTP Basic，RFC 6749 错误体 |
| `src/handler/gateway.rs` | `POST /v3/gateway` 按 method 分发到原 service |
| `src/handler/openapi.rs` | `GET /v3/openapi.yaml` 返回嵌入的 OAS |
| `src/middleware/auth.rs` | 仅网关：`Authorization: Bearer`，401 信封 + `WWW-Authenticate` |
| `src/types/envelope.rs` | 网关统一 `{code,msg,request_id,data}` |
| `src/types/gateway.rs` | 三个 method 常量 |
| `src/types/posts.rs` / `src/service/posts.rs` | 列表字段 `data` → `items`（避免信封 `data.data`） |
| `src/handler/{posts,photos,imgdef}.rs` | **删除** |
| `docs/API.md` `docs/SPEC.md` `docs/openapi.yaml` | 按当前协议重写，无旧路径说明 |

### 要点

- **破坏性协议变更**：`/auth/token`、`/api/*` 一律 404 信封
- Token：`grant_type=client_credentials`；凭证 body 或 Basic（Basic 优先）；可选 `scope` 空格分隔 method
- 网关：`{"method","biz_content"}`，Bearer 鉴权；未开通 method → 403 `code` 40300
- Token 报文遵守 RFC 6749（非信封）；网关一律信封
- 预置应用 `ak_loadtest` / `sk_loadtest_secret_1`，三个 method 全开
- 访问日志字段 `username` → `client_id`；params 带 RPC `method`

## 5. 验证

- `cargo clippy --bin upupt -- -D warnings`：PASS
- 本机 `http://127.0.0.1:3001` curl：
  - `GET /v3/openapi.yaml` 含 `tokenUrl: /v3/oauth/token`
  - `/auth/token`、`/api/posts` → 404 `code` 40401
  - form 与 Basic 换票 200，`token_type=Bearer`，`Cache-Control: no-store`
  - 错误 grant → 400 `unsupported_grant_type`；错 secret → 401 `invalid_client` + Basic WWW-Authenticate
  - 未知 scope → 400 `invalid_scope`
  - 网关 `upupt.posts.search` keyword=gRPC user_id=6 → id 18；`X-Request-Id` 回传
  - 无 Bearer → 401 `code` 40100 + Bearer WWW-Authenticate
  - 未知 method → 400 `code` 40400；根对象多余字段 → 422 `code` 42200
  - 仅 scope=`upupt.posts.search` 再调 photos → 403 `code` 40300
  - photos jpeg 40×30 成功；imgdef 自比对 `distance=0` `matched=true`
  - `page=0` → 400 `code` 40001
- 未跑 `cargo clippy --all-targets`（`src/bin/gen_imgs.rs` 原有 pedantic 告警，未改）

## 6. 部署提示

- 必须重建并重启 `upupt` 进程
- 压测脚本改为：先 `POST /v3/oauth/token`，再 `POST /v3/gateway` 带 Bearer 与 `method`
- 可执行文件同级需有更新后的 `config/app.toml`（含 `[[apps]]`）
- `cargo run` 时配置从二进制目录 `config/` 读取，需把 `app.toml` 放到 `target/debug/config/`（`start.sh` 的项目根布局不受影响）

## 7. 未做 / 明确不做

- 未做 HMAC 每请求签名（鉴权走 OAS 规定的 tokenUrl + Bearer）
- 未做限流、IP 白名单、行级权限、Webhook
- 未保留旧 URL 或旧 `{error,request_id}` 信封开关
