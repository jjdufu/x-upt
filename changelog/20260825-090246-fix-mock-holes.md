# Changelog — 2026-08-25 09:02:46 +0800

会话/任务主题：修 mock 逻辑漏洞、收口 gettoken 别名、补流水号/404/WSDL 与文档

## 1. 背景与目标

- 源码评审：九面主路径能用，但 REST Content-Type、SOAP 空元素、JSON-RPC 通知、任务不校验/不隔离、WS 数字 `id`、404 空 body、sign 非 form、文档与契约有缺口
- 目标：按已测漏洞改代码；去掉 gettoken `corpid`/`corpsecret`；WSDL 补 output；手册与实现对齐

### 要点

- **破坏性：** JSON-RPC 缺 `id` 不再回 `"id":null`，改为 204；gettoken 不再认 `corpid`/`corpsecret`；未知 method 的任务提交改为 400，不再 202 后再 failed；`GET /jobs/{id}` 只能查本 client
- sign `/gateway.do` 非 form：由 415 改为 200 `isv.missing-parameter`（与「该路径一律 200」一致）
- REST envelope 打开时，任务路径的非法 JSON 仍用 rest 失败 JSON
