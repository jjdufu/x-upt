# Changelog — 2026-08-25 09:43:22 +0800

会话/任务主题：`start.sh` 改名为 `run.sh`，按 start / status / stop / restart 方案落地

## 1. 背景与目标

- 运维脚本叫 `scripts/start.sh`，四个子命令和文件名不一致
- stop 不等待进程 10 秒 graceful；stdout/stderr 丢进 `/dev/null`；status/stop 误查项目根配置
- 目标：入口改为 `scripts/run.sh`，四个命令按 `docs/运行方案.md` 执行

## 2. 代码改动

| 路径 | 变更 |
|------|------|
| `scripts/start.sh` → `scripts/run.sh` | 改名；start/status/stop/restart；配置跟可执行文件同级；控制台日志；SIGTERM 等 12 秒 |
| `docs/运行方案.md` | 四个命令的动机、现状、做法、落地、验证 |
| `docs/SPEC.md` | 启动节指向 `scripts/run.sh` |
| `.gitignore` | `upupt.pid`、`/upupt` |

### 要点

- 无参数等于 `start`；status 未跑 exit 1；已在跑再 start exit 0
- 判活：PID 正整数 + `comm=upupt` + 非僵尸
- 业务日志仍走 `[log]`；启动横幅和配置错误进 `logs/upupt.console.log`

| 项 | 结论 |
|----|------|
| schema / init-dbs / 迁移 | **无需修改** |
| 说明 | 无数据库 |

## 4. 配置

- 未改 `config/app.toml`
- 进程仍读可执行文件同级 `config/app.toml`

## 5. 验证

- `bash -n scripts/run.sh` PASS
- `-h` 列出 start/status/stop/restart，exit 0 PASS
- 未知命令 exit 1 PASS
- 无二进制：`start` exit 1；`status`/`stop` 仍可跑 PASS
- 陈旧 PID：status 报 stale 且不删文件；stop 删除 PASS
- 项目根 `upupt` + `config/app.toml`：start 写 PID，`comm=upupt`；再 start 报 already running PASS
- SOAP `GET :3006/soap` 200、oauth openapi 200、rest 未知路径 404 PASS
- restart 换新 PID，SOAP 仍 200；stop 后 status exit 1、端口释放 PASS

## 6. 部署提示

- 用 `./scripts/run.sh {start|status|stop|restart}`，不要再调 `scripts/start.sh`
- 把 `upupt` 放到项目根（与 `config/` 并列），或 `cargo build --release` 并把 `config/` 拷到 `target/release/`
- 验证时从 `target/debug/upupt` 硬链到项目根 `upupt`，当前进程由 `run.sh` 托管
