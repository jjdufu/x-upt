# 日志行加 event 字段

## 背景

异步任务完成、过期时写的日志行沿用提交时的 request_id、method、path、ip、UA，level 也一样，和真实入站请求分不开。排查时容易把任务状态行当成调用方又发了一次请求。

## 代码

`src/types/logger.rs` 新增 `LogEvent`（`access` / `job_done` / `job_expired`），`LogEntry` 加 `event` 字段，紧跟 `level`。HTTP、WS 访问行写 `access`；`jobstore` 的 `emit_job_line` 按调用处写 `job_done`（成功、失败）或 `job_expired`（运行前过期、后台清理过期）。request_id 规则不变。
