# upupt 信封画像一览

对接 mazbri 透明上游时，**先读本文**，再对照 `config/app.toml`。改造原理见 [信封改造手册.md](./信封改造手册.md)；机器可读副本：同目录 `信封画像.json`。

- **画像 ≠ 一定加密**：有的只换票/凭据，有的只签名，有的签名+字段加密。
- 六面常开：`3010`–`3015`。密钥只写相对路径，内容在 `config/keys/envelope/`（`scripts/gen_envelope_keys.sh` 生成）。
- grpc（3005）与本文无关；联调可关。

## 速查表

| face | port | profile | path | 加密? | 签名/加密 | 鉴权形态 | 密钥（相对路径） |
|---|---:|---|---|---|---|---|---|
| envelope_token_plain | 3010 | issue | POST `/issue` | 否 | — | form username/password 发牌 | `issue_username` / `issue_password` |
| envelope_token_plain | 3010 | call | POST `/call` | 否 | — | Header `Authorization: Bearer ` 用牌；业务 JSON | 本面票桶 |
| envelope_token_crypt | 3011 | issue | POST `/issue` | 否 | — | JSON id/secret 发牌 | `issue_id` / `issue_secret` |
| envelope_token_crypt | 3011 | call | POST `/call` | **是** | SM4-ECB 字段 `data` | Bearer 用牌 + 密文字段 | `sm4.key` |
| envelope_sign_plain | 3012 | call | POST `/call` | 否 | MD5 hex，sorted_kv+后缀 key | JSON `sign` | `md5.key` |
| envelope_sign_plain | 3012 | sm3 | POST `/sm3` | 否 | SM3 hex，raw 签 `payload` | JSON `sign`+`payload` | —（digest） |
| envelope_sign_crypt | 3013 | aes | POST `/aes` | **是** | HMAC-SHA256 → AES-ECB 字段 `payload`（sign_then_encrypt） | JSON `sign`+`payload` | `hmac.key` + `aes.key` |
| envelope_sign_crypt | 3013 | sm4 | POST `/sm4` | **是** | SM4-CBC（IV random_prefix）→ HMAC-SM3（encrypt_then_sign） | JSON `sign`+`payload` | `sm4.key` + `hmac_sm3.key` |
| envelope_cred_plain | 3014 | call | GET `/call` | 否 | — | query `company_id`；体空 | `company_id` |
| envelope_cred_plain | 3014 | header | POST `/header` | 否 | — | header `appcode`；业务 JSON | `appcode` |
| envelope_cred_crypt | 3015 | call | POST `/call` | **是** | DES-CBC 字段 `params`（IV=key）；响应明文 JSON | form `username`+密文 `params` | `cred_username` + `des.key` |

## 画像明细（与当前 `config/app.toml` 同步）

### 3010 `envelope_token_plain`

**issue**：`body_kind=form`，`fail_in=http`，`token_response_field=access_token`。字段：`username`/`password` → form/auth。

**call**：`body_kind=json`，`biz_rest=true`，`token_prefix="Bearer "`。字段：`authorization` → header/token。业务字段走 REST 三 method 形状。

### 3011 `envelope_token_crypt`

**issue**：JSON `id`/`secret` 发牌，同上回 `access_token`。

**call**：Bearer + `crypt_alg=sm4_ecb_pkcs7`，`cipher_scope=fields`，`cipher_fields=["data"]`，`crypt_encoding=base64`，`key=config/keys/envelope/sm4.key`。槽位：`authorization` header/token；`data` json/cipher。

### 3012 `envelope_sign_plain`

**call（MD5）**：`sign_alg=md5`，`sign_encoding=hex`，`hex_case=lower`，`canon=sorted_kv`，`canon_skip=["sign"]`，`canon_sep="&"`，`canon_suffix_key=true`，`key=…/md5.key`，`biz_rest=true`。槽位：`sign` json/sign；其余业务字段进 sorted_kv。

**sm3**：`sign_alg=sm3`，`canon=raw`，`canon_fields=["payload"]`，`biz_rest=false`。槽位：`sign`、`payload`(biz)。

### 3013 `envelope_sign_crypt`

**aes**：`fail_in=envelope`；`sign_alg=hmac_sha256`；`crypt_alg=aes_ecb_pkcs5`；`cipher_fields=["payload"]`；`order=sign_then_encrypt`；`key=…/aes.key`，`sign_key=…/hmac.key`。槽位：`sign`、`payload`(cipher)。

**sm4**：`sign_alg=hmac_sm3`；`crypt_alg=sm4_cbc_pkcs7`；`iv_from=random_prefix`；`order=encrypt_then_sign`；`key=…/sm4.key`，`sign_key=…/hmac_sm3.key`。

### 3014 `envelope_cred_plain`

**call**：GET，`body_kind=empty`，query `company_id` ↔ `secrets=…/company_id`，`biz_rest=true`。

**header**：POST JSON，header `appcode` ↔ `…/appcode`，`biz_rest=true`。

### 3015 `envelope_cred_crypt`

**call**：form；`crypt_alg=des_cbc_pkcs5`，`cipher_fields=["params"]`，`iv_from=key`，`key=…/des.key`；`secrets=…/cred_username`；`response_crypt_alg=none`（响应明文 JSON）。槽位：`username` form/auth；`params` form/cipher。

## 与九面网关（对照，非信封六面）

| face | port | 说明 |
|---|---:|---|
| oauth_gateway | 3000 | `POST /v3/oauth/token` 换票；`POST /v3/gateway` body `{method,biz_content}` + Bearer（本面票） |
| sign_gateway | 3001 | `POST /gateway.do` form + HMAC-SHA256（与信封 sign 面不同适配器） |

详例见 [API.md](./API.md)。

## mazbri 透明上游对接提示（通用）

| 画像类型 | 建议 adapter | auth / crypto 要点 |
|---|---|---|
| token plain/crypt call | `http_json`（或带 oauth 的 http） | 先换本面票；crypt 用 `named_fields` + SM4-ECB on `data` |
| sign plain MD5 | `http_json` + crypto profile | `sorted_kv` + `canon_key_affix=suffix` + MD5 hex；`allow_insecure` |
| sign plain SM3 | 同上 | raw 签 `payload` 字段字节；digest-as-sign |
| sign crypt aes/sm4 | 同上 | `sign_then_encrypt` / `encrypt_then_sign`；字段 `payload`；IV 按画像 |
| cred plain | `http_json` | query/header 静态凭据 |
| cred crypt DES | `http_json` form | DES-CBC `params`；IV=key；username form |
| oauth_gateway | `http_envelope` | oauth_cc + method/biz_content |
| sign_gateway | `sign_form` | HMAC form |

上游基址（容器打 box 上的 upupt）：优先 `http://172.23.0.1:<port>`（`mazbri_mazbri` 网关），备选 box `enp0s3`。
